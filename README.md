# 🛹 SKATE BOARD RACE — 3D Extreme Downhill Racing

An adrenaline-pumping 3D downhill skateboard racing game built with **React**, **Three.js**, and **TypeScript**. Carve mountain highways, clash with rival skaters, dodge traffic, drift hairpin turns, and hit supersonic speeds with Super Boost!

---

## 🎮 Game Features

- **Dynamic 3D Downhill Physics**: Multi-phase downhill highway featuring mountain switchbacks, graffiti tunnels, glass tubes, and off-road dirt trails.
- **Rival Clash AI**: Battle against 6 rival skaters (**Axel, Blaze, Kira, Vortex, Ghost, Nova**) for podium finishes.
- **Highway Traffic & Near-Miss Combos**: Thread the needle through traffic cars to earn adrenaline near-miss speed bursts and bonus coins.
- **Super Boost & Nitro Strips**: Trigger turbo boosts to exceed 150 km/h with custom particle jet trails.
- **Drift Mechanics**: High-speed slide glove carving with dynamic sparks and tire smoke.
- **Tuning Garage**: Upgrade Top Speed, Handling & Drift, Super Boost Duration, and Clash Bumper Armor using collected coins.
- **Interactive Audio Engine**: Procedural synthesizers for wind rumble, engine revs, drifts, collisions, and coin pickups.

---

## 📱 Mobile & Desktop Controls

The game is fully responsive and optimized for both **touchscreen mobile devices** (smartphones and tablets) and **desktop keyboards/mice**.

### 📱 Mobile Controls (Two-Thumb Layout):
- **Left Thumb**: Tap & hold **`◀ LEFT`** or **`RIGHT ▶`** to steer and carve.
- **Right Thumb**: Tap **`⚡ BOOST`** to ignite Super Boost.
- **Alternative**: Drag anywhere on the screen left or right to steer.

### 💻 Desktop Controls:
- **`A` / `D`** or **`Arrow Left` / `Arrow Right`**: Steer & Drift
- **`SPACEBAR`** or **`Shift`**: Super Boost
- **Mouse Drag**: Drag left/right to steer

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm, yarn, or pnpm

### Installation
```bash
# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Production Build
```bash
npm run build
```

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript
- **3D Graphics Engine**: Three.js (WebGL with shadows, procedural textures, and dynamic particle systems)
- **Icons**: Lucide React
- **Build Tool**: Vite 8
